# md-parser
## general
This is a parser for markdown files (.md)
It converts markdown files into html files which can be then run in the browser
## how it works
It uses regex parsing to match str scenarios to the file
If it finds a match, it extracts the data into the html format and saves it
## files
The 2 files: test.html and test.md are the test files for this project
The file: parser.py is the main script
## updates
I might add support for more file types and their conversions in future updates
